The spun trefoil in the No-Intersection model

1. Continuum picture: Artin spinning

The spun trefoil is a knotted two-sphere in four dimensions. Start with a trefoil presented as a knotted arc \(\alpha\) in the half-space \(z\ge 0\), with both endpoints on the plane \(z=0\). Spin the half-space around that plane by replacing the height \(z\) with polar coordinates in a new two-plane: \[ (x,y,z)\longmapsto (x,y,z\cos\theta,z\sin\theta), \qquad 0\le \theta <2\pi . \] Interior points of the arc sweep circles. The two endpoints, where \(z=0\), do not sweep circles; they stay fixed on the spin axis. Topologically this is \(\alpha\times S^1\) with the two boundary circles collapsed to two points, hence a two-sphere \(S^2\).

Why it is knotted. For a spun arc, the complement has the same knot group as the original arc closure. For a trefoil this group is \[ \pi_1 \cong \langle a,b\mid aba=bab\rangle, \] which is non-abelian. An unknotted two-sphere in \(S^4\) has complement group \(\mathbb Z\). The non-abelian complement group is the topological reason this two-sphere is knotted.

2. The trefoil arc used by the code

The implementation starts from a \(5\times5\) grid diagram of the trefoil. The markers are \(O_i=(i,i)\) and \(X_i=(i,i+3\!\!\pmod 5)\). Each column joins its two markers vertically; each row joins its two markers horizontally; all vertical strands pass over all horizontal strands. The code cuts the closed diagram open on row 4 between columns 2 and 3, a segment without crossings.

3. Lattice construction: a swept solid, not a solve

The lattice directions are \[ 0=x,\qquad 1=y,\qquad 2=\zeta,\qquad 3=w . \] The script uses \(N=18\), grid spacing 3 in the \(x,y\) plane, \(Z_{\rm under}=2\), \(Z_{\rm over}=4\), and spin-axis offset \((\zeta,w)=(9,9)\). A round circle of radius \(z\) in the continuum spin is replaced by the square, or Chebyshev, circle of radius \(z\) in the \((\zeta,w)\) plane. The square replacement is a PL isotopic discretization of the same spin; the spacing and height separation are chosen so the lattice wedge product does not create artificial corner contacts.

3.1 The key implementation trick

The code does not first draw the surface \(F\) and then solve \(dn=F\). It constructs a 3-dimensional solid \(C\) on the dual lattice: \[ C = \alpha \times \{\text{square disk in }(\zeta,w)\}. \] In four dimensions, a dual 3-cell is naturally paired with the complementary primal link. Therefore this dual 3-chain can be stored directly as the integer Villain 1-form \(n\). Taking the exterior derivative then takes the boundary: \[ F = dn = \partial C . \]

The two assignment lines in build_n are the entire constructor: 

if tau == 0:  # x-step
    n[1, ax + 1, ay, cells, cells] += -direction
else:         # y-step
    n[0, ax, ay + 1, cells, cells] += +direction

The rest of the script is verification. The stored output has shape \((4,18,18,18,18)\) for \(n\) and \((6,18,18,18,18)\) for \(dn\). Only the \(n_x\) and \(n_y\) components are nonzero, because the swept solid is built from x- and y-runs of the arc:

4. What is verified numerically

The numerical checks are deliberately local and code-native. They use the package exterior derivative \(d\) and wedge product \(\wedge\), the same conventions used by the No-Intersection action. The action itself tests validity by computing \(q=dn\wedge dn\) and requiring it to vanish on every hypercube.

What the computation does and does not prove. The numerical checks prove that the lattice object is a valid embedded two-sphere configuration for the No-Intersection model. They do not independently compute \(\pi_1\) of the lattice complement. The knottedness claim comes from the continuum Artin-spin theorem plus the fact that the code starts from a trefoil grid diagram and uses PL-isotopic square spin circles with enough spacing to avoid lattice artifacts.
